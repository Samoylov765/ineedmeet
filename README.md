# ineedmeet

Минимальный видеозвонок в браузере: одна ссылка, два участника.

## Запуск локально

    npm install
    npm start

Открыть http://localhost:3000, нажать «Создать комнату», ссылку открыть во второй вкладке.

## Как работает

- Видео и звук идут напрямую между браузерами (WebRTC).
- `server.js` только передаёт служебные сообщения (WebSocket) и раздаёт страницы.
- Комната создаётся по адресу `/new` и живёт, пока в ней кто-то есть. Максимум 2 человека.

## Важно

Камера в браузере работает только по HTTPS (или на localhost).
